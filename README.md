# Spin Calculator — iOS

The iOS version of **Spin Calculator**, a tool for spin-coating speed calculations.

This directory contains the iOS project. The Android version is maintained separately in [`Android_App`](../Android_App/).

## Purpose

Spin Calculator supports spin-coating work by helping users calculate spin speeds. Consult the app interface for the available inputs, units, and calculation options.

## Project setup

Build requirements and installation instructions will be added alongside the iOS project files. These should specify:

- The development tools and versions required.
- The minimum supported iOS version.
- Any dependencies and how to install them.
- How to build and run the app on a simulator or device.

## Usage

1. Open Spin Calculator on your iOS device.
2. Enter the required values using the units shown in the app.
3. Run the calculation and review the result.

Spin-coating results depend on the material, substrate, and processing conditions. Validate calculated settings experimentally for your process.
